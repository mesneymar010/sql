HADOOP : EXAM DATASETS GUIDE
Every question below = GROUP BY. Two ways to answer:
  1) GroupBy.java (no code change):
       hadoop jar groupby.jar GroupBy <in> <out> <keyCol> <valueCol> <op> [filterCol=value]
  2) Payroll.java (write code): mapper key = data[keyCol], value = data[valueCol],
     reducer = op (see HOW-TO-CHANGE-PAYROLL.txt). Filter: if (data[col].trim().equals("value"))
  Python backup (Windows, from 3-HADOOP folder; Ubuntu: cat + python3 + forward slashes)
Columns counted from 0. Header line is skipped automatically. Expected output from the given CSVs.
Payroll.java (IntWritable) prints whole numbers; GroupBy (DoubleWritable) prints 10500.0
