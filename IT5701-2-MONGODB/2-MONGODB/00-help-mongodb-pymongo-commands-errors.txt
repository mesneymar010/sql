6. mongo (old) vs mongosh (new)
============================================================
SAME in both: insertOne, insertMany, find, findOne, updateOne, updateMany,
              deleteOne, deleteMany, aggregate, distinct, sort, limit, drop

Use the new names. Old ones are deprecated in mongosh:
  insert()  -> insertOne() / insertMany()
  update()  -> updateOne() / updateMany()
  remove()  -> deleteOne() / deleteMany()
  count()   -> countDocuments({})
               (very old shell below 4.0: db.users.find().count())

7. QUERY OPERATORS (quick list)
============================================================
$eq $ne $gt $gte $lt $lte $in $nin      comparison
$and $or $not                           logical
$exists  { phone: { $exists: true } }   field present
/^A/     { name: /^A/ }                 starts with A
/a$/     { name: /a$/ }                 ends with a
/an/i    { name: /an/i }                contains "an", ignore case

$push  db.users.updateOne({name:"Bob"}, {$push: {skills: "java"}})

$set $unset $inc $mul $push $pull       update operators ($mul: multiply a field)

$match $group $sort $project $limit     aggregate stages
$sum $avg $min $max                     group accumulators
$multiply $divide $add $subtract        math inside $project / $group
$cond                                   if-else inside aggregate
$expr                                   compare two fields in find (MongoDB 3.6+)
db.users.aggregate([{ $group: { _id: "$city", maxAge: { $max: "$age" } } }])

SQL -> MongoDB
  WHERE            find({...})  or  { $match: {...} }
  GROUP BY x       { $group: { _id: "$x", ... } }
  COUNT(*)         { $sum: 1 }
  SUM(a)           { $sum: "$a" }
  SUM(a*b)         { $sum: { $multiply: ["$a", "$b"] } }
  HAVING           { $match: {...} } after $group
  ORDER BY a DESC  .sort({ a: -1 })  or  { $sort: { a: -1 } }
  LIMIT / TOP 3    .limit(3)  or  { $limit: 3 }
  SELECT a, b      find({}, { _id: 0, a: 1, b: 1 })
  LIKE 'A%'        { name: /^A/ }
  a < b (2 cols)   find({ $expr: { $lt: ["$a", "$b"] } })

8. PYMONGO : INSTALL THE RIGHT VERSION
============================================================
Step 1: check server version:  mongod --version
Step 2: install
  server 4.4 or newer   ->  py -m pip install pymongo
  server 4.0 / 4.2      ->  py -m pip install "pymongo<4.14"
  server 3.x            ->  py -m pip install "pymongo<4"
Step 3: check:  py -c "import pymongo; print(pymongo.version)"

(pip picks a pymongo that fits your Python automatically,
 but NOT one that fits your server - that's why step 1 matters.)

-- quick connection test
py -c "from pymongo import MongoClient; print(MongoClient('mongodb://localhost:27017/', serverSelectionTimeoutMS=3000).server_info()['version'])"

9. PYMONGO : NAMES (shell vs python)
============================================================
shell            python
insertOne        insert_one
insertMany       insert_many
findOne          find_one
updateOne        update_one
updateMany       update_many
deleteOne        delete_one
deleteMany       delete_many
countDocuments   count_documents
sort({age:-1})   sort("age", -1)
keys: age:       keys must be in quotes: "age":
$gt              "$gt" (in quotes)

DON'T use in python (removed in pymongo 4): insert(), update(), remove(), count()

10. COMMON ERRORS
============================================================
'mongosh' is not recognized
  -> try "mongo", or use full path to mongosh.exe, or reopen cmd after install

'mongod' is not recognized
  -> use full path: "C:\Program Files\MongoDB\Server\<ver>\bin\mongod.exe"

ECONNREFUSED 127.0.0.1:27017  /  connect failed
  -> server not running: net start MongoDB  or  mongod --dbpath C:\data\db

NonExistentPath: Data directory C:\data\db not found
  -> mkdir C:\data\db

Address already in use (port 27017)
  -> server is already running, just open mongosh

System error 5 / Access is denied (net start)
  -> open cmd as Administrator

ServerSelectionTimeoutError (python)
  -> server not running, or wrong URL. Start server first.

ModuleNotFoundError: No module named 'pymongo'
  -> py -m pip install pymongo   (use the same "py"/"python" you run the script with)

'pip' is not recognized
  -> py -m pip install pymongo

ConfigurationError / "wire version" / "server version ... not supported"
  -> pymongo too new for the server. See section 8.

TypeError: 'Collection' object is not callable (python)
  -> method name wrong or removed (count/insert/update/remove). See section 9.

SyntaxError in shell
  -> missing } or ], or used Python style "True" instead of true

DuplicateKeyError / E11000
  -> same _id inserted twice
